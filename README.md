# 📝 Todo アプリ

シンプルで拡張性の高い **フルスタック Todo 管理アプリ** です。
ユーザーごとにタスクを登録・編集・削除でき、
安全な認証とデータ永続化を備えています。

---

## ⚙️ 技術スタック

| 領域               | 使用技術                           |
| ------------------ | ---------------------------------- |
| フロントエンド     | **React / TypeScript / Vite**      |
| バックエンド       | **Node.js / Express / TypeScript** |
| データベース       | **PostgreSQL**                     |
| インフラ・デプロイ | **Render（HTTPS・SSL 対応）**      |

---

## 🧩 機能概要

### ✅ RESTful API 設計

`/todos` エンドポイントを中心に、`GET / POST / PUT / DELETE` による **CRUD 操作** を実装。
認証済みユーザーごとに Todo を安全に管理できます。

### 🗃️ データ永続化

`PostgreSQL + pgモジュール` を使用し、
`users`・`todos` テーブルを構築。
外部キー制約と自動タイムスタンプを活用して、堅牢なデータ管理を実現。

### 🔄 再利用性と拡張性

- API 層と DB 層を明確に分離
- React / Vue / Svelte など、**任意のフロントエンドフレームワーク**から利用可能
- `.env` ファイルで **DB 接続・CORS 設定** を柔軟に切り替え可能
- カラム追加・テーブル拡張など、**要望に応じてカスタマイズ可能**

---

## 🔒 セキュリティと運用性

- **httpOnly Cookie** による安全なトークン管理
- **CORS + credentials: include** による認証付き通信
- **Render の自動 SSL（HTTPS）** による通信暗号化
- **環境変数（.env）** による設定分離で本番環境でも安全に動作
